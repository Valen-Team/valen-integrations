# Data handling

This plugin sends the supplied text, optional image, questions and model ID to the configured Valen endpoint. Image URLs supplied by Dify are downloaded before inference. API keys are stored as Dify provider credentials and sent only to the configured API. The plugin adds no persistence or logging; Dify execution history and endpoint retention policies still apply. See https://valen-team.github.io/docs/valen/api/data-handling/.
